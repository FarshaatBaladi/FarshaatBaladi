## Project standards

Each project added to this portfolio should aim to include:

1. A clear problem statement and project purpose
2. Features and screenshots or a demo where useful
3. Technologies used (only those actually used)
4. Setup and run instructions
5. Example usage and expected output
6. Known limitations and possible future improvements
