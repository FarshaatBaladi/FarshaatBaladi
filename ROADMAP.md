## Planned projects

**Status for every project in this section: Planned.** These are concepts only; none should be described as implemented, completed, or deployed until the work actually exists and has been checked.

### 1. AI-Powered Study Assistant

A study companion to help learners organise materials, generate summaries, and create practice questions using AI.

**Learning goals:** Full-stack development, AI API integration, prompt design, and user data management.

### 2. AI Resume Analyzer

A tool to compare a resume with a job description and provide structured feedback on skills, keywords, and clarity.

**Learning goals:** Text processing, AI integration, file handling, and web application development.

### 3. Face Recognition Attendance System

An attendance system concept using face recognition, with appropriate consent, privacy safeguards, secure data handling, and a manual alternative.

**Learning goals:** Python, computer vision, database design, and authentication.

### 4. Cloud File Storage System

A web application concept for uploading, organising, downloading, and managing user files.

**Learning goals:** Full-stack development, file uploads, cloud storage, access control, and database integration.

### 5. Automated Software Testing Platform

A platform concept for managing test cases, running automated checks, and showing test results in a dashboard.

**Learning goals:** Test automation, software quality assurance, backend APIs, reporting, and CI workflows.

## Project standards

Each project should aim to include:

1. A clear problem statement and project purpose
2. Features and screenshots or a demo where useful
3. Technologies actually used (not just planned)
4. Setup and run instructions
5. Example usage and expected output
6. Tests and known limitations
7. Possible future improvements
8. An accurate status and repository link
